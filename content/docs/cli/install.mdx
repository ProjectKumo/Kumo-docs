---
title: Install The CLI
description: How to put kumo on your PATH via the GUI or a manual symlink.
---

The `kumo` executable lives inside the app bundle at:

```text
Kumo.app/Contents/Helpers/kumo
```

Kumo manages a `/usr/local/bin/kumo` symlink that points at this binary so
you can run `kumo` from any terminal.

## GUI Installer

The recommended path is the first-run onboarding sheet or
**Settings → General → Command Line Tool**. macOS asks for administrator
authorization once because `/usr/local/bin` is not user-writable.

See [Command-line tool](/docs/getting-started/command-line-tool) for the
full walkthrough.

## Manual Symlink

You can also create the symlink yourself:

```bash
sudo ln -sfn /Applications/Kumo.app/Contents/Helpers/kumo /usr/local/bin/kumo
```

Manual symlinks are detected by `kumo status` and the Settings panel, so you
can switch back to the GUI installer later without surprises.

## Verify

```bash
ls -l /usr/local/bin/kumo
kumo --version
kumo status --json | jq '.ok'
```

## Source-tree Development

For development work without installing the bundle:

```bash
cd KumoApp
make run-cli ARGS="status --json"
```

This runs `swift run kumo` under the hood and is intentionally not the
same path as the bundled binary. App Intents, Spotlight, and the Services
menu all require the full `Kumo.app` bundle.

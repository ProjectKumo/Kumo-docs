---
title: Welcome to Kumo
description: A calm native macOS client for the Mihomo proxy core, with a SwiftUI app and an agent-friendly CLI.
---

Kumo is a Mac utility for connecting quickly without turning everyday proxy
management into a network operations dashboard. The first screen is designed to
answer four questions at a glance:

- Is Kumo connected?
- Which outbound mode is active?
- Is the macOS system proxy enabled?
- Which profile and proxy group are currently in use?

Advanced capabilities — DNS, TUN, rule providers, logs, overrides, and
Sub-Store — stay discoverable in dedicated sections, so daily use remains
focused.

## What Kumo Is

| Area              | What Kumo provides                                                              |
| ----------------- | ------------------------------------------------------------------------------- |
| Native macOS app  | SwiftUI interface around `NavigationSplitView`, Settings, and a status item.    |
| Shared core       | `KumoCoreKit` owns Mihomo lifecycle, profile generation, controller, and state. |
| CLI for everyone  | `kumo` supports stable command names, `--json`, dry-run, and predictable exits. |
| Mihomo discovery  | Bring your own binary, use Homebrew, or let Kumo install a managed core.        |
| Safe defaults     | Empty profiles produce a direct config; system proxy changes can be previewed.  |

## Stay Calm

Kumo's first version intentionally avoids privileged helpers. System proxy and
TUN changes use macOS administrator authorization only when they truly need
elevated privileges, and Kumo never registers a VPN profile. See
[Permissions](/docs/reference/permissions) for the full list.

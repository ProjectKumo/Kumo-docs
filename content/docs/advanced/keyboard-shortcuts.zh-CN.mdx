---
title: 键盘快捷键
description: Kumo 在 GUI 和菜单栏中监听的所有按键。
---

Kumo 有一组精简、有意的键盘快捷键。它们在主窗口或菜单栏获得焦点时
均可用。

## 生命周期

| 快捷键   | 操作                                            |
| ---------- | ----------------------------------------------- |
| `⇧⌘S`      | 启动核心。                                      |
| `⌘.`       | 停止核心。                                      |
| `⌃⌘R`      | 重启核心。                                      |

## 模式

| 快捷键 | 操作            |
| -------- | ----------------- |
| `⌘1`     | 切换到 **规则**。 |
| `⌘2`     | 切换到 **全局**。 |
| `⌘3`     | 切换到 **直连**。 |

## 配置

| 快捷键 | 操作                              |
| -------- | ----------------------------------- |
| `⌘R`     | 刷新活跃配置。                      |
| `⌥⌘R`    | 刷新所有到期配置。                  |

## 窗口

| 快捷键 | 操作                              |
| -------- | ----------------------------------- |
| `⌘,`     | 打开**设置**。                      |
| `⌃⌘S`    | 切换侧边栏。                        |
| `⌘W`     | 关闭主窗口(保留在菜单栏)。          |
| `⌘Q`     | 退出 Kumo。                         |

## 搜索

| 快捷键 | 操作                              |
| -------- | ----------------------------------- |
| `⌘F`     | 聚焦当前目的地中的搜索字段(配置、代理、连接等)。 |

## 辅助功能

每个纯图标控件都有一个暴露给 VoiceOver 的文本标签,屏幕阅读器用户
可以按名称导航。Tab 循环从左到右遍历侧边栏,从上到下遍历内容面板。

进阶单元涵盖 GUI 以外的所有内容：`kumo` 命令行工具、自定义配置、覆写规则、自动化钩子,以及面向编码 Agent 的技能包。

所有这些功能都建立在 GUI 使用的同一套 `KumoCoreKit`  facade 之上,因此命令行与 GUI 的状态始终一致。

## 约定

- 代码示例均为真实命令,可直接复制运行。
- JSON 示例使用实际输出格式 — `{ ok, data?, error? }` — 脚本和 Agent 可据此分支。
- 如果 GUI 已覆盖同一主题,页面会链接回
  [上手](/docs/getting-started) 版本。

这些设计决策的工程原理见
[参与贡献](/docs/contributing) 单元。

**订阅** 是一段 URL,指向一份代理节点列表,由你的代理服务商托管。
大多数服务商会在它们的控制台里给你这段 URL,通常标记为
"Clash 订阅" 或 "Clash URL"。

Kumo 使用 Clash / Mihomo 订阅格式。如果服务商给的是 Clash 订阅,
你可以直接粘贴进来。

## 首次启动

第一次打开 Kumo 时会出现一个简短的引导面板,共四步:

1. **欢迎** —— 一句简单的 "你好,这里是 Kumo"。
2. **命令行工具** —— 可选;详见
   [高阶用户](/docs/power-user/command-line)。
3. **Agent 技能** —— 可选;详见
   [高阶用户](/docs/power-user/agent-skills)。
4. **完成** —— 进入主界面。

可选步骤现在可以跳过,以后随时可以在 **设置** 里启用。

## 添加第一个订阅

<Steps>

<Step>
### 打开「配置」面板
在左侧边栏点击 **配置**。
</Step>

<Step>
### 添加一个新配置
点击右上角的 **+** 按钮。会弹出一个表单,要求你填入 URL 或本地
文件。
</Step>

<Step>
### 粘贴订阅 URL
把服务商给你的 URL 粘到 **URL** 字段。给这个配置起一个你能认出的
名字 —— 比如 "Main" 或服务商的名字。
</Step>

<Step>
### 保存并让 Kumo 下载
点击 **保存**。Kumo 会下载订阅、解析代理列表,然后在配置详情面板里
显示出来。
</Step>

<Step>
### 设为活跃
在列表中右键点击新建的配置并选择 **设为活跃**,或者点击它一次然后
按 **使用此配置** 按钮。
</Step>

</Steps>

现在你已经有了一个配置,但 Kumo 还没启动。该让它跑起来了。

## 启动 Kumo

切换到 **概览**(侧边栏顶部)。左侧的大状态卡片显示 **已停止**。
点击 **启动**。

一两秒后,状态会变成 **运行中**。右侧的四张小卡片也都会活过来:

- **配置** —— 显示当前活跃的配置和流量计数。
- **流量** —— 实时上传和下载的小图表。
- **系统代理** —— 切换 macOS 是否把流量送到 Kumo。
- **TUN** —— 用于全局路由(详见
  [高阶用户](/docs/power-user))。

## 把 Mac 的流量送进 Kumo

仅仅启动 Kumo 只是让代理在 `127.0.0.1` 上 *可用*。要让日常浏览
流量真的走代理,需要在概览界面把 **系统代理** 切换到 **开**。

<Callout type="info">
系统代理使用的是 macOS 内置的 `networksetup` 开关,跟
**系统设置 → 网络** 里的是同一个。它**不会**安装 VPN 配置。你可以
随时关掉,macOS 会立即恢复。
</Callout>

打开 Safari,访问
[ipinfo.io](https://ipinfo.io) 或
[whatismyip.com](https://whatismyip.com),你应该能看到你选择节点的
所在地区。

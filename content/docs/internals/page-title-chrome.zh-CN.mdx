Kumo 使用 macOS 工具栏 / 导航标题作为主要页面标题表面。详情页面不应在内容区域内重复相同标题作为大标题。

## 规则

每个顶级目的地应通过 `ContentView` 导航 chrome 暴露其标题。页面内容应从第一个有意义的控件、摘要卡片、表单节、表格或空状态开始。

不要添加重复的页内大标题,如:

```swift
Text("Proxies")
    .font(.largeTitle.bold())
```

共享的 `KumoPage(title:)` 包装器保留 `title` 参数用于调用点可读性,但它不得将该标题渲染为内容。它是一个内容布局包装器,不是第二个标题栏。

## 理由

macOS 窗口已经在统一工具栏中提供了清晰的标题区域。在页面内重复目的地名称会消耗垂直空间、削弱层级,并使卡片密集的页面感觉像一个嵌套 sheet,位于独立标题之下。

## 例外

仅当页内标题命名一个未被窗口或导航标题代表的子节时才使用它。`Form`、`Table`、卡片和分组控件内的节标题仍然合适。

## 检查清单

在发布新页面或重构页面之前:

- 目的地标题在工具栏 / 导航 chrome 中可见。
- 内容区域不重复相同标题作为大标题。
- `KumoPage(title:)` 不被用作渲染第二个页面标题的理由。
- 空状态仍然提供自己的状态专属标题,如 `No Proxy Groups`。

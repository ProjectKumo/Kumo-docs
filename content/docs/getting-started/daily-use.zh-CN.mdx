只要 Kumo 启动并加载了配置,日常的使用其实很简单:
大部分时间你只会看 **概览** 屏幕、偶尔在 **代理** 里挑个节点,
其余时间让它从菜单栏里默默运行就好。

## 概览屏幕

概览是 Kumo 的主页。分两块:

- **左侧:** 一张大的状态卡片。显示 Kumo 是否运行、当前出站模式、
  活跃的配置,以及一个启动 / 停止按钮。
- **右侧:** 四张小卡片 —— 配置、流量、系统代理、TUN ——
  每张告诉你一件具体的事。

你可以拖动左右之间的分隔条来调整空间。Kumo 会记住你的设置。

### 状态卡片

状态卡片有三种状态:

- **已停止** —— 代理处于关闭状态。点击 **启动** 来开启。
- **运行中** —— 代理处于开启状态。卡片显示活跃配置和出站模式。
- **错误** —— 出问题了。卡片显示一条简短的错误信息。详见
  [排查问题](/docs/getting-started/troubleshooting)。

### 四张小卡片

| 卡片         | 显示什么                                                                      |
| ------------ | ----------------------------------------------------------------------------- |
| 配置         | 当前活跃配置的名字、已用流量,以及一个刷新按钮。                              |
| 流量         | 实时的上传 / 下载,以及一个 60 秒的迷你图表。                                 |
| 系统代理     | macOS 是否把流量送到 Kumo,带一个开关。                                       |
| TUN          | Kumo 是否在路由你整台 Mac 的流量。详见 [进阶](/docs/advanced)。         |

如果 Kumo 处于 **已停止** 状态,卡片会显示最后一次记录的值,这样
你可以在重新启动核心之前先瞥一眼。

## 代理屏幕

切换到侧边栏的 **代理**,可以看到你的代理组和节点。

- 第一层列出订阅里的 **组**(通常会有一个 "Proxy" 组,可能还有
  "Streaming" 或 "Direct" 之类)。
- 点击某个组可以看到它的 **成员** —— 实际的代理节点。
- 对于 **select** 类型的组,点击任意节点就可以选中。Kumo 会记住
  你的选择并告诉 Mihomo。
- 对于 **自动** 类型的组(URLTest、Fallback、LoadBalance),组会
  自己管理选择。Kumo 显示当前选中的节点,但你不能直接覆盖它。

每个节点会显示国旗(在 Kumo 能识别国家时)和一颗延迟标签,根据上一次
测速的结果显示绿 / 橙 / 红。点击组上的 **测延迟** 按钮可以刷新数据。

## 菜单栏

菜单栏里有一个 Kumo 图标。点击它会弹出一个小菜单,包含最常用的控制:

- 启动 / 停止核心。
- 切换出站模式(规则 / 全局 / 直连)。
- 切换系统代理。
- 打开主窗口。
- 退出 Kumo。

图标会根据当前状态变化 —— 运行时为实心、停止时为空心,需要你注意
某件事时会带一个小角标。

<Callout type="info">
如果你看不到菜单栏图标,可能是其他应用(Bartender、Hidden Bar、
iStat Menus)把它藏起来了。打开 **设置 → 通用**,确认
**显示菜单栏图标** 是开着的。
</Callout>

## Sub-Store 屏幕

Kumo 内置了 **Sub-Store**,这是一个小工具,用来在一个地方管理多份
代理订阅。如果你只需要一份订阅,可以忽略它。详见
[Sub-Store](/docs/getting-started/sub-store) 上手指南。

## 通常不需要碰的东西

大多数用户整天会停留在 **概览** 和 **代理** 里。侧边栏里的其他
目的地 —— 连接、日志、规则、核心、系统代理、TUN、DNS —— 是给特定
场景准备的:

- **连接** 在你想知道 "现在是哪个 app 在用代理?" 时很有用。
- **日志** 在某些东西出问题、你想看 Mihomo 在说什么时很有用。
- **核心、系统代理、TUN、DNS** 是给精细控制用的。默认值对大多数人
  来说已经够用。

如果你发现自己想深入这些之一,跳到
[进阶](/docs/advanced) 单元。

Kumo is a native macOS app that routes traffic through the
[Mihomo](https://github.com/MetaCubeX/mihomo) proxy core. Bring a
subscription URL or a YAML / Clash config file, and Kumo provides a
SwiftUI app, a menu bar item, and an optional command-line tool with
matching functionality.

Start, stop, switch nodes, and toggle system proxy from the menu bar.
Advanced settings remain accessible without cluttering the main
interface.

## Requirements

- **macOS 15 Sequoia or newer**, running on Apple Silicon (M1 / M2 / M3 / M4).
- A proxy **subscription URL** from a provider, or a trusted YAML / Clash
  config file.

<Callout type="info">
No VPN provider, developer account, or NetworkExtension entitlement is
required. Kumo does not trigger the **Allow VPN Configuration** prompt.
</Callout>

## What Kumo is not

- Not a VPN service. A separate subscription is required for proxy
  servers.
- Not a NetworkExtension. Kumo does not request the **Allow VPN
  Configuration** prompt and does not install a system VPN profile.
- Not Windows or Linux software (today). Kumo is macOS-only and targets
  macOS 15 Sequoia or newer on Apple Silicon.

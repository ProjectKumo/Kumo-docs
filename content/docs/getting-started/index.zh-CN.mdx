Kumo 是一款原生 macOS 应用,通过
[Mihomo](https://github.com/MetaCubeX/mihomo) 代理核心转发流量。提供
订阅 URL 或 YAML / Clash 配置文件,Kumo 会提供 SwiftUI 应用界面、
菜单栏图标,以及一个功能对等的可选命令行工具。

从菜单栏即可启动、停止、切换节点、开关系统代理。高级设置始终
可用,不会干扰主界面。

## 系统要求

- **macOS 15 Sequoia 或更高版本**,运行在 Apple Silicon (M1 / M2 / M3 / M4) 上。
- 一个来自代理服务商的**订阅 URL**,或一份可信的 YAML / Clash 配置文件。

<Callout type="info">
无需 VPN 服务商、开发者账号或 NetworkExtension 权限。Kumo 不会触发
**允许 VPN 配置** 的系统提示。
</Callout>

## Kumo 不是什么

- 不是 VPN 服务。需要单独的订阅才能连接到代理服务器。
- 不是 NetworkExtension。Kumo 不会请求 **允许 VPN 配置** 的提示,也不会安装系统级 VPN 配置。
- 目前不支持 Windows 或 Linux。Kumo 仅面向 macOS,目标平台为 macOS 15 Sequoia 及以上版本的 Apple Silicon。

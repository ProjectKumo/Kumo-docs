If only one subscription is needed, this page can be skipped. The
standard flow on the [Subscriptions](/docs/getting-started/subscriptions)
page is sufficient.

For **two or more** subscriptions — for example a fast one and a
backup, or one per region — Kumo bundles a companion app called
**Sub-Store** that keeps them in one place and allows merging.

## What Sub-Store does

- Holds several subscription URLs in one place.
- Combines them into a single output (one merged proxy list).
- Applies small tweaks (rename groups, filter nodes by keyword) without
  editing YAML by hand.
- Hands the output to Kumo as a profile, the same way a regular
  subscription does.

It is not required. Many users operate with one subscription and never
open Sub-Store.

## Open Sub-Store

Click **Sub-Store** in the Kumo sidebar. The first time it opens,
Kumo prepares the bundled backend in the background and shows the
Sub-Store interface in a native panel.

Two main tabs are visible:

- **Subscriptions** — raw subscription URLs.
- **Combined** — outputs that merge one or more subscriptions.

## Add a subscription to Sub-Store

1. Go to the **Subscriptions** tab.
2. Click **Add subscription**.
3. Paste the URL, give it a name, and pick the right **format**
   (almost always **Clash**).
4. Save.

Sub-Store fetches the subscription and shows the node count.

## Combine subscriptions

1. Go to the **Combined** tab.
2. Click **Add combination**.
3. Pick which subscriptions to include.
4. Optional: filter or rename nodes.
5. Save.

Each combination gets its own URL that looks like
`http://127.0.0.1:.../share/...`. That URL is what you paste into Kumo
as a profile.

## Feed Sub-Store output to Kumo

1. Copy the Sub-Store share URL for the combination.
2. In Kumo, go to **Profiles → +**.
3. Paste the URL.
4. Save.

Kumo now has a profile that always reflects the current Sub-Store
output. Refreshing the profile in Kumo refreshes the merged result.

<Callout type="info">
Sub-Store runs **locally** as long as Kumo is running. The share URL
only works on the local Mac — nothing is exposed to the wider internet.
</Callout>

## Custom Sub-Store backend

Some users prefer to host Sub-Store themselves (on a NAS, a VPS, or in
a container) and share it across multiple devices. Kumo supports custom
Sub-Store backends. See
[Sub-Store hosting](/docs/advanced/sub-store-hosting) in the
Advanced track.

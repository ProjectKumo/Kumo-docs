Kumo ships as a notarized `.dmg` disk image. The installation process
is the same as any other Mac app.

## Requirements

- macOS 15 Sequoia or newer
- An Apple Silicon Mac (M1, M2, M3, M4)
- About 200 MB of free disk space

Intel Macs are not supported in the first release.

## Install

<Steps>

<Step>
### Download the latest release
Open the
[GitHub release page](https://github.com/ProjectKumo/KumoApp/releases/latest)
and download the file that ends in `-arm64.dmg`.
</Step>

<Step>
### Open the DMG
Double-click the downloaded file. macOS verifies the signature and shows
a window with the Kumo icon and an alias to Applications.
</Step>

<Step>
### Drag Kumo to Applications
Drag the **Kumo** icon onto the **Applications** alias inside the same
window. macOS copies the app.
</Step>

<Step>
### Eject and launch
Right-click the mounted disk image in Finder and pick **Eject**, then
open Kumo from **Applications** or from Launchpad.
</Step>

</Steps>

The first time you open Kumo, macOS Gatekeeper may display a warning:
*"Kumo can't be opened because it was downloaded from the internet."*
Click **Open**. This prompt should only appear once.

## File locations

After installing, Kumo resides in `/Applications/Kumo.app`. App data —
subscriptions, settings, and logs — is stored separately under the home
folder.

<Callout type="info">
To remove Kumo, drag `Kumo.app` to the Trash. To also delete saved data,
open Finder, press `⇧⌘G`, paste `~/Library/Application Support/Kumo`,
and move that folder to the Trash as well.
</Callout>

## Updates

Kumo checks for updates automatically every few minutes while running,
and shows a notification when a new version is available. Manual checks
are available from **Settings → Updates**. See
[Stay up to date](/docs/getting-started/updates).

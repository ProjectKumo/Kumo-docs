Kumo ships as a notarized **`.dmg`** disk image. Installing it is the
same shape as installing any other Mac app.

## Before you start

You need:

- macOS 15 Sequoia or newer
- An Apple Silicon Mac (M1, M2, M3, M4)
- About 200 MB of free disk space

Intel Macs are not supported in the first release.

## Install

<Steps>

<Step>
### Download the latest release
Open the
[GitHub release page](https://github.com/ProjectKumo/KumoApp/releases/latest)
and download the file that ends in `-arm64.dmg`.
</Step>

<Step>
### Open the DMG
Double-click the downloaded file. macOS verifies the signature and shows
a window with the Kumo icon and an alias to Applications.
</Step>

<Step>
### Drag Kumo to Applications
Drag the **Kumo** icon onto the **Applications** alias inside the same
window. macOS copies the app.
</Step>

<Step>
### Eject and launch
Right-click the mounted disk image in Finder and pick **Eject**, then
open Kumo from **Applications** or from Launchpad.
</Step>

</Steps>

The first time you open Kumo, macOS Gatekeeper may say *"Kumo can't be
opened because it was downloaded from the internet."* Click **Open**.
You should only see this prompt once.

## Where Kumo lives on disk

After installing, Kumo lives in **`/Applications/Kumo.app`** like any
other Mac app. The app's own data — your subscriptions, settings,
logs — lives separately under your home folder, where you do not have to
think about it.

<Callout type="info">
If you ever want to remove Kumo, drag `Kumo.app` to the Trash. To also
delete the saved data, open Finder, hit `⇧⌘G`, paste
`~/Library/Application Support/Kumo` and trash that folder too.
</Callout>

## Updates

Kumo checks for updates automatically every few minutes while it is
running, and shows a notification when a new version is ready. You can
also check manually from **Settings → Updates**. See
[Stay up to date](/docs/getting-started/updates).

The Power User track is for when the GUI is no longer enough — or when
the GUI is great, but you want to wire Kumo into Shortcuts, Spotlight,
a coding agent, or your own shell scripts.

Everything here is built on top of the same `KumoCoreKit` facade the
GUI uses, so the GUI and the command line always agree on state.

## Conventions you will see in this track

- Code examples are real commands. You can copy and run them.
- JSON examples are the actual output shape — `{ ok, data?, error? }`
  — that scripts and agents can branch on.
- Where the GUI does the same thing, the page links back to the
  [For Everyone](/docs/for-everyone) version so you can hand it to a
  colleague.

If something here gets too deep and you want the engineering view of
*why* Kumo does it that way, jump to
[Contributing](/docs/contributing).

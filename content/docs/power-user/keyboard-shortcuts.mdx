---
title: Keyboard Shortcuts
description: Every key Kumo listens to, in the GUI and the menu bar.
---

Kumo has a small, deliberate set of keyboard shortcuts. They all work
when the main window or menu bar is focused.

## Lifecycle

| Shortcut   | Action                                          |
| ---------- | ----------------------------------------------- |
| `⇧⌘S`      | Start the core.                                 |
| `⌘.`       | Stop the core.                                  |
| `⌃⌘R`      | Restart the core.                               |

## Mode

| Shortcut | Action            |
| -------- | ----------------- |
| `⌘1`     | Switch to **Rule**.    |
| `⌘2`     | Switch to **Global**.  |
| `⌘3`     | Switch to **Direct**.  |

## Profile

| Shortcut | Action                              |
| -------- | ----------------------------------- |
| `⌘R`     | Refresh the active profile.         |
| `⌥⌘R`    | Refresh all due profiles.           |

## Window

| Shortcut | Action                              |
| -------- | ----------------------------------- |
| `⌘,`     | Open **Settings**.                  |
| `⌃⌘S`    | Toggle the sidebar.                 |
| `⌘W`     | Close the main window (stays in menu bar). |
| `⌘Q`     | Quit Kumo.                          |

## Search

| Shortcut | Action                              |
| -------- | ----------------------------------- |
| `⌘F`     | Focus the search field in the active destination (Profiles, Proxies, Connections, etc.). |

## Accessibility note

Every icon-only control has a textual label exposed to VoiceOver, so a
screen reader user can navigate by name. The Tab cycle goes left-to-right
through the sidebar, top to bottom through the content pane.
